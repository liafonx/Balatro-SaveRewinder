# Save Rewinder

[English](README.md) | 简体中文

**撤销失误，自由探索，永不丢失进度。**

Save Rewinder 在你游玩小丑牌时自动创建存档点，让你可以一键回溯到任意最近时刻。

-  **自动快照** — 自动记录每个关键时刻（选盲注、出牌、商店）。
- ⚡ **即时撤销** — 按 `S`（键盘）或 `L3`（手柄）立即回退。
- 🔁 **快速读档** — 按 `L`（键盘）或 `R3`（手柄）立即重载。
- ⭐ **收藏存档** — 可将重要节点标记为收藏，并只筛选显示收藏存档。
- ✏️ **重命名存档** — 可在存档面板中修改存档标题。
- 💀 **结算页回溯** — 在游戏结束面板可直接回溯到最近一次存档。
- 🧪 **自由实验** — 放心尝试策略，回退后的存档会一直保留，直到你进行新的操作。
- 🛡️ **分数溢出保护** — 即使出现 `naneinf/inf` 也能安全回退/读档（可选限制到 `1.8e308`）。

## 安装

1. 为 Balatro 安装 [Steamodded](https://github.com/Steamopollys/Steamodded)
2. 下载并解压[最新版本](https://github.com/Liafonx/Balatro-SaveRewinder/releases) — 其中包含一个 `SaveRewinder` 文件夹
3. 将 `SaveRewinder` 文件夹复制到游戏的 `Mods` 文件夹中
4. 启动 Balatro — 可以在 Mod 列表中看到 **Save Rewinder**

> ⚠️ **重要**：确保 `Mods/SaveRewinder/` 中直接包含模组文件（如 `main.lua`），而不是另一个嵌套的 `SaveRewinder` 文件夹。

> 📦 **Thunderstore 用户**：文件位于 zip 根目录。创建 `Mods/SaveRewinder/` 并将所有文件解压到其中。最终结构：`Mods/SaveRewinder/main.lua`。

## 快速开始

### 操作方式

| 操作 | 键盘（默认） | 手柄（默认） |
|------|------|------|
| 回退一个存档（可更改） | `S` | 按下左摇杆（L3） |
| 快速读档（可更改） | `L` | 按下右摇杆（R3） |
| 打开存档列表（可更改） | `Ctrl+S` | `X`（仅限暂停菜单） |

> **提示**：打开**暂停菜单 → 选项**，点击**橙色"存档列表"按钮**（或按 `Ctrl+S` / `X`）即可浏览并恢复任意存档。

### 存档列表图标按钮

- **打开收藏列表** — 文字按钮，仅显示收藏存档。
- **★ 编辑收藏存档** — 星形图标按钮，进入标记模式并切换收藏状态。
- **✏️ 重命名模式** — 铅笔图标按钮，进入后可在列表中直接编辑存档标题。
- **▶ 当前存档** — 三角图标按钮，跳转到当前正在使用的存档。

使用方法：
1. 点击 **★ 编辑收藏存档** 进入标记模式。
2. 点击存档条目切换收藏状态（待提交改动会在条目旁显示白色圆点标记）。
3. 点击 **★ 保存标记更改** 提交；直接关闭面板会丢弃待提交改动。
4. 使用 **打开收藏列表** 进行筛选，使用 **▶ 当前存档** 快速跳转当前位置。

重命名流程：
1. 点击 **✏️** 按钮进入重命名模式。
2. 点击某条存档并编辑标题。
3. 再次点击该行（或切换到其他行）以暂存草稿（重命名待提交改动也会在条目旁显示同样的白色圆点标记）。
4. 再次点击 **✏️** 提交全部暂存重命名草稿。

### 存档面板中的 Enter 键行为

当存档面板打开时：
- **标记模式 + Enter**：等同点击 **★ 保存标记更改**（提交标记改动并退出标记模式）。
- **重命名模式 + 正在编辑某行 + Enter**：等同再次点击该行（暂存该行草稿并退出该行编辑）。
- **重命名模式 + 未在编辑某行 + Enter**：等同点击 **✏️**（提交全部暂存重命名草稿并退出重命名模式）。

## 结算页回溯

当你本局失败时，结算面板会显示一个按钮，可直接回到最近一次存档继续。

## 配置选项

在 Steamodded 的 Save Rewinder 模组菜单中可设置：

- 选择保存时机（盲注、出牌、回合结束、商店）。
- 切换盲注图标显示与动画效果。
- 设置保留的底注数量（默认：4）。
- 设置每回合每类型最多存档数（默认：16）。
- 溢出分数处理（限制到1.8e308或保留为naneinf）。
- 自定义键盘和手柄快捷键。

## 存档位置

存档存储在 `[Profile]/SaveRewinder/`。

> ⚠️ **注意**：存档仅保留**当前游戏**，开始**新游戏**会清空旧存档。中途退出并继续游戏时历史记录会保留。
